# 动作库方案（2026-11-12 用户提出）

## 用户要的

动作单独存：同一个动作在不同天练，记录共用；替代动作是独立的动作，各有自己的组数 / 次数区间 / 重量 / 记录；换动作更方便。

## 现在是怎么存的（核实过代码）

- 动作定义抄在每个训练日里。引体向上、面拉、肱二弯举、悬垂举腿在正手日和反手日各一份，改一边另一边不变。
- "上次"、预填、进阶提示其实已经按动作 id 跨天查（history.js `lastSetsFor`、progression.js `recentSessionsFor` 遍历全部记录）。上面 4 个动作两天用同一个 id，所以记录已经共用。但计划编辑里新加的动作每次起新 id（`ex-时间戳`），自己在另一天加"同一个动作"就不共用。
- 替代动作只是"名字 + 可选重量"（`alternates: [{name, load?}]`），挂在原动作下：组数、次数区间、休息、档位、进阶提示都沿用原动作；记录挂在"原动作 id + 替代名"下（`set.usedAlternate`）。所以"锤式弯举"作肱二弯举的替代、和作上肢B 自己的动作，是两份不相通的记录；折线图只算原动作的组，用替代做的不进折线。

## 新的存法

- 计划里加动作库 `exercises`：每个动作一条，带 id、名称、部位、重量（档位 / 助力 / 自重 / 每边）、组数区间、次数区间、休息秒数、每侧 / 按米、备注、替代动作（存别的动作的 id）。
- 训练日只存"按什么顺序做哪几个动作"：`exercises: [{ id, note? }]`，可带一句当天备注。
- 训练记录：每组记下实际做的动作 id。"上次"、预填、进阶提示、折线全按实际动作 id 查，不管哪天练的、是作为主动作还是替代做的。
- 训练中换动作：换成的动作用它自己的组数、次数、重量、休息、上次记录和进阶提示。
- 实现：运行时把训练日"展开"成完整动作对象（库里的定义 + 当天备注），训练页 / 历史页的大部分代码不用改；查定义时先查当天的动作，再查整个库（替代动作不在当天列表里）。

## 旧数据迁移（手机第一次打开新版时自动做一次）

- 迁移前把旧计划和全部记录原样存一份在库里；App 版的自动备份文件照旧。
- 主动作：同一个 id 合成一条；两天备注不一样的，变成各自的当天备注。
- 替代动作：名字和已有动作完全一样的直接并过去（锤式弯举 → 上肢B 的锤式弯举）；其余的各建一个新动作，id 由名字算出（同名永远同 id，旧备份导入也对得上），组数 / 次数 / 休息先抄原动作的，重量用替代动作写的（没写就是首次做时填），之后在动作库里改。
- 旧记录里"用替代动作做的组"改记到对应动作的 id 下。
- 导入旧版导出的备份文件走同一套迁移。

## 要用户定的

1. 组数、次数区间、休息时长跟着动作走（所有天一样），训练日只能加一句当天备注；还是每个训练日能单独改组数 / 次数？推荐前者。
2. 内置计划里名字相近、可能是同一个动作的，要不要合并（合并后记录合在一起）：
   - 斜上哑铃卧推（斜上卧推的替代）＝ 上斜哑铃卧推（上斜器械推胸的替代）
   - 斜上器械推胸（斜上卧推的替代）＝ 上斜器械推胸（上肢B 主动作）
   - 哑铃侧平举（绳索侧平举的替代，15 lb）＝ 侧平举（推日，15 lb）
   - 哑铃弯举（锤式弯举的替代，25 lb）＝ 肱二弯举（拉日，25 lb）
   手机上的计划改过名字的以手机为准。另一个办法是做"合并两个动作"按钮，以后自己合。
3. 训练中"换动作"：只从设好的替代里选，还是下面再加"从动作库选其他动作"？推荐都要。

## 实施步骤（每步验收 + 提交）

1. 动作库数据结构 + 迁移 + 展开；训练 / 历史 / 进阶按实际动作 id 查。界面不变。验收：旧数据迁移后首页、训练、历史、折线和迁移前一样；用替代做过的组出现在替代动作自己的"上次"里。
2. 训练页换动作：替代动作用自己的组数 / 次数 / 重量 / 休息 / 上次 / 进阶提示；（如定）从动作库选。
3. 计划编辑：动作库页（列表、新建、修改、隐藏不用的）；训练日"从动作库添加"；替代动作从动作库里勾。
4. 历史：替代动作也有自己的折线；历史编辑里换动作按 id。
5. （如要）合并两个动作。
